# Shared / Common UI Components (`src/components/common/`)

Shared components used across both Candidate and HR Portals.

## 📁 Component Directory Structure

- `Navbar.jsx`: Global header navigation.
- `Sidebar.jsx`: Adaptive role-based sidebar navigation.
- `Badge.jsx`: Eligibility and status badges (`Tier-1`, `Eligible`, `SLA Warning`).
- `Button.jsx`: Styled interactive buttons.
- `Modal.jsx`: Reusable modal dialog wrapper.
- `LoadingSpinner.jsx`: Accessible loading indicator.
